# Daily Glow — sitio web

Sitio responsive de e-commerce para Daily Glow, inspirado en las referencias aportadas.

## Funciones
- Catálogo con filtros por categoría.
- Carrito persistente en el navegador (localStorage).
- Suma/resta de cantidades y total.
- Pedido del carrito por WhatsApp al 11 5860-2204.
- Botones a Instagram @daily.glow.ar.
- Dato de Mercado Pago: dailyglow.mp con botón para copiar.
- Diseño responsive para celular y PC.

## Cómo usar
Abrí `index.html` en un navegador. No necesita servidor para funcionar.

## Personalización
Los precios están cargados en `index.html` dentro de la constante `PRODUCTS`.
